# Правки 07.11.2026 (5) — библиотека игр, профили ТВ, теги, переводы

Проверено: компиляция Windows-ветки; тесты `tst_gamelibrarymodule_scan`
(8/8), `tst_androidtv_console` (11/11), `tst_audiotags` (10/10, файлы
созданы сторонними средствами — mutagen и libsndfile); стенд снимков
интерфейса — 349 снимков без предупреждений QML. **На медиацентре не
проверялось** — пункты в `CHECKLIST.md`.

## 1. Кэш размеров игр (§15 п.5)

Размер уже сохранялся в `game_info.json`, но **не обновлялся никогда** —
после обновления игры показывался старый. Теперь рядом сохраняется
«отпечаток» (`sizeStamp`): время изменения папки `game/` и её подпапок
первого уровня, для архива — размер и время файла. При сканировании
библиотеки отпечаток сверяется (одно чтение каталога, без обхода файлов);
не совпал — размер пересчитывается в фоне.

## 2. Проверка места перед распаковкой игры (остаток §15 п.4)

`SevenZip::unpackedSize` — размер после распаковки по списку файлов архива
(`7zr l -slt`). Не хватает места (с запасом 0,5 ГБ) — распаковка не
начинается, уведомление «… не распакована: мало места на диске D:/ — нужно
N ГБ, свободно M ГБ». Не удалось узнать размер — распаковка как раньше.

## 3. Удаление профиля Android TV с данными (§18 п.16)

«Удалить профиль» спрашивает: «Удалить с данными» (папка `<avd>.avd` — диск
Android, приложения, вход в аккаунты — и `<avd>.ini`), «Оставить данные»,
«Отмена». В вопросе — размер данных. AVD, общий с другим профилем, и
подозрительные имена (с путями) не удаляются.

## 4. Теги mp3/flac в караоке (§9.2 п.2)

TagLib не подключён, поэтому источник «теги» был недостижим, и нейросеть
грузилась для каждого файла. Новый `AudioTags` без сторонних библиотек и
внешних процессов: ID3v2.2–2.4 (все кодировки), ID3v1, Vorbis-комментарии
FLAC (+ длительность). Однобайтовые строки в русских mp3 — почти всегда
cp1251: распознаётся по содержимому («Beyoncé» остаётся Latin-1).

## 5. Неиспользуемые строки перевода (§19 п.7)

Из 81 ключа, отмеченного в аудите, к этому моменту оставалось 13 —
удалены (ru и en). Проверено, что ключи нигде не собираются из частей.
