# Правки 07.11.2026 (6) — сжатие игр, запуск без PowerShell, караоке

Проверено: компиляция Windows-ветки и наличие всех функций WinAPI в
подключённых библиотеках; тест `tst_gamelibrarymodule_scan` (11/11, в т.ч.

интерфейса. **На медиацентре не проверялось** — пункты в `CHECKLIST.md`.

## 1. Сжатие игр «на месте» (новое)

Библиотека → удержание на установленной игре → «Сжать (игра останется
рабочей)». Папка `game/` сжимается средствами Windows (WOF, LZX — то же, что
CompactGUI, через системный `compact.exe /c /s /a /i /exe:lzx`). Игра
запускается как обычно; экономия обычно 20–50 %. Временного места не нужно.

- Прогресс — по строкам вывода `compact` (файл за файлом), крестик
  останавливает: уже сжатые файлы остаются сжатыми и работают.
- Размер в библиотеке теперь — **место на диске** (`GetCompressedFileSizeW`),
  для обычных игр он не меняется.
- В `game_info.json`: `compressed`, `sizeBeforeCompress` (для уведомления
  «N → M ГБ» и проверки места при снятии сжатия).
- «Снять сжатие» (`compact /u /exe`) — сначала проверка свободного места.
- Во время сжатия игру нельзя архивировать/разархивировать (и наоборот).
  После разархивации флаг сжатия снимается — из архива файлы выходят обычными.

## 2. Запуск игр без PowerShell (§4 п.5)

`launch.ps1`, созданный программой и не изменённый вручную, разбирается
(`InstallUtils::parseLaunchScript`), и exe запускается напрямую через
`ShellExecuteEx` — как `Start-Process`, с запросом прав администратора, если
игре они нужны. Экономит 0,5–2 с на запуск PowerShell и не вызывает
подозрений антивируса. Скрипт изменён вручную или не наш — запускается сам
скрипт, как раньше. Нет exe — сразу сообщение, без ожидания 30 с.

## 3. Подвисание при входе в караоке

На стенде экран создаётся за 10–20 мс — причина, видимо, в Windows-части.
Сделано: системный диалог выбора файла создаётся при первом нажатии, а не
при входе на экран; создание экранов дольше 80 мс пишется в журнал
(`[UI] screen created in N ms`). Нужна строка из журнала — по ней будет
видно, что тормозит.

## 4. Клавиатура в Android TV (§18 п.13)

Со схемой B эмулятор — активное окно, и все клавиши, кроме стрелок, Enter,
Esc и кнопок пульта, идут в него напрямую — набор текста должен работать без
распознавания устройства. Пункт переведён в «проверить».
