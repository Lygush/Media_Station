### 1.2 Что осталось

#### B. Эмулятор — фоновый процесс (архитектура «прозрачного окна сверху») — 🟡 сделано, ждёт проверки

Реализовано 06.11 (CHANGES_2026-11-06_3): после проявления ТВ эмулятор
становится активным окном, MediaStation — `SW_HIDE`; под оверлеем
MediaStation показывается без активации (alpha 0 → 128), после закрытия
снова прячется. Курсор убирается к краю экрана и не двигается. Ниже —
исходное описание проблемы.

`AndroidTVWindow.cpp:451–468`: эмулятор показывается **под** окном
MediaStation, MediaStation становится alpha = 0, остаётся TOPMOST и забирает
фокус (`SetForegroundWindow(m_mediaStationHwnd)`).

Последствия:
- Процесс эмулятора не foreground: в клиентских Windows foreground-процесс
  получает увеличенный квант; фоновые процессы могут попадать под
  Power Throttling / EcoQoS, на процессорах Intel 12+ — на E-ядра. Для
  эмулятора, где vCPU и аудиотаймер просыпаются каждые 10 мс, это и есть
  «периодические» провалы. (Отказ от троттлинга для qemu уже сделан — это
  смягчает, но не заменяет статус переднего плана.)
- Полноэкранное layered-окно поверх 1440p-видео — лишняя композиция DWM на
  каждый кадр, эмулятор теряет прямой вывод (independent flip).
- Окно MediaStation с alpha = 0 продолжает жить: анимации под чёрным
  `transitionOverlay` перерисовывают всё окно.

**Это решение я считаю ошибочным.** Оно появилось, чтобы ловить кнопку «Меню»
и показывать оверлей. Но хук клавиатуры (`G72KeysModule`) уже глобальный, а
оверлей — отдельное Tool-окно (`OverlayModule`, `OverlayScreen.qml:80–84`),
которому прозрачное полноэкранное окно не нужно.

→ Схема:
1. При показе ТВ: эмулятор — окно без рамки на весь экран, **на переднем плане
   и с фокусом**; MediaStation — `SW_HIDE`. `WS_EX_LAYERED` не нужен.
2. «Меню» ловится существующим LL-хуком → окно оверлея (TOPMOST, небольшое).
   При закрытии — фокус обратно эмулятору.
3. Выход из ТВ: показать MediaStation, скрыть эмулятор.
4. Ввод уже идёт через консоль эмулятора и от фокуса не зависит.

Для теста до переделки: запустить эмулятор вручную той же командой из
`Android_TV.log` (строка `emulator -avd …`) при закрытом MediaStation и
сравнить на слух и по строкам `Audio:`.

Не закрыто:
- 🟡 **Ввод через консоль эмулятора (§1.2 D) на эмуляторе 36.4 не работает**
  (заменён вводом через gRPC, п. 7а, ждёт проверки; `sendevent` в образе с
  Google Play не работает — нет root):
  `event send` принимается, но до Android не доходит (проверено `getevent`,
  07.11). Ввод идёт через `adb input keyevent` — запуск JVM в госте на
  каждую пачку нажатий, то есть возвращается нагрузка, от которой уходили
  (рывки звука при листании). Варианты: (а) `adb shell` с постоянным
  `input`-процессом нельзя — `input` разовый; (б) писать события напрямую в
  `/dev/uinput` из гостя маленьким нативным бинарником (без JVM) — самый
  дешёвый путь; (в) gRPC-интерфейс эмулятора (`-grpc`, `sendKey`) — штатный
  и быстрый. Первая клавиша после запуска ТВ — с задержкой ~1,8 с
  (самопроверка); результат проверки можно запоминать по версии эмулятора.
- Строка `emulator could not take foreground` в журнале — Windows не отдала
  активность эмулятору; звук тогда как до схемы B.

## 2. Обновление

Сделано: версия из `app_version.txt` (сервер читает её из exe), Updater
переносит недостающее из старой `tools/`, `models/`, `logs/`; архивы
обновлений не копятся; сервер не удаляет готовый архив при ошибке.

### 2.2 Что осталось

1. **Перенос всей папки приложения** ради замены exe и пары DLL. Отсюда весь
   сложный код отката (rename/пофайловый перенос/повторы), зависимость от
   того, держит ли Проводник или антивирус папку.
2. 🟡 «Мажорное» обновление всё ещё **удаляет старую `tools/`** после переноса
   недостающего (`UpdaterWindow.cpp:766–818`). Безопасно, только пока перенос
   отрабатывает без ошибок.
3. **Каждый раз — полный пакет**: exe + все Qt DLL + QML-плагины + (по
   умолчанию) весь `tools`.
4. **Нет подлинности.** SHA-256 присылает тот же, кто присылает архив.
   Любой компьютер в сети может отправить «обновление»
   (`NetworkServer.cpp:103–131` принимает без вопроса) — одно нажатие «ОК», и
   чужой exe запущен.
6. Если программа стоит в `Program Files`, обновление без прав администратора
   не сработает (`UpdaterWindow` создаёт новую папку рядом) — ставить в папку
   пользователя (установщик) или запускать Updater с повышением.

### 2.3 Предлагаемая схема

**Пакет = манифест + только файлы приложения:**
```
manifest.json  { version, files: [{path, size, sha256}], signature }
MediaStation.exe, *.dll, platforms/, qml/ (плагины Qt), Updater/…
```
`tools/`, `data/`, `logs/` в пакет **не входят никогда**. Тяжёлые компоненты
(Android SDK, модели, ffmpeg, DS4Windows) — отдельные компоненты со своей
версией (§10.2).

**Доставка — pull.** Сервер публикует последнюю версию (HTTP в локалке или
GitHub Releases). Клиент при старте и по кнопке «Проверить обновления»
скачивает манифест, сравнивает хэши с установленными файлами и докачивает
**только изменившиеся** (обычно exe + 1–3 DLL).

**Замена — пофайловая:** `file → file.old`, `new → file`; список `.old` —
готовый откат. Новая версия через 30–60 с работы пишет «healthy»; если нет —
при следующем старте Updater возвращает `.old`. Код Updater сокращается в разы.

**Подпись:** ECDSA P-256 через Windows CNG (`BCryptVerifySignature`) — без
новых библиотек. Закрытый ключ на сервере, открытый вшит в клиент.
Подписывается манифест.

**Сервер — одна кнопка** «Собрать и опубликовать» (и режим командной строки
для Qt Creator/CI): exe → `windeployqt` → манифест → подпись → опубликовать.

Если pull не хочется — можно оставить push, но с манифестом/дифом и
сопряжением (§3.3).

## 24. zapret (flowseal/zapret-discord-youtube) — как встроить

**Что это.** Сборка zapret под Windows (MIT): `winws.exe` и драйвер WinDivert
(bol-van/zapret) + готовые стратегии `general*.bat` и `service.bat`. WinDivert
перехватывает исходящий трафик **всей системы** и для доменов из списка
подмешивает «обманные» пакеты для DPI провайдера.

**Android TV получает обход автоматически**: эмулятор выходит в интернет через
сокеты процесса qemu на этом же компьютере.

**Как встроить:**
1. Компонент на складе: `tools/zapret/` (путь без кириллицы и спецсимволов).
2. Установка **службой один раз** через `service.bat` с выбранной стратегией.
   MediaStation сам `winws` не запускает (каждый запуск — права администратора).
3. MediaStation показывает статус службы и кнопку «Проверить».
4. **Game Filter не включать** — он расширяет обход на порты игр.
5. Связка с §23: DoH из AdGuard Home; домены YouTube — в белый список AdGuard.

**Риски:** антивирусы ругаются на WinDivert (`RiskTool.Multi.WinDivert`) —
папку в исключения; **античиты** в некоторых онлайн-играх реагируют на
драйвер (в zapret-win-bundle есть `windivert-hide`) — проверить на ваших играх.

### 24.1 Автоматизация zapret

В релизе (`service.bat` v1.10.4, `utils/test zapret.ps1`, `utils/targets.txt`)
уже есть стратегии (23 файла), служба `zapret` с именем стратегии в реестре
(`HKLM\System\CurrentControlSet\Services\zapret`, значение
`zapret-discord-youtube`), автотест стратегий (`curl` по сайтам из
`targets.txt`) и проверка версии по
`raw.githubusercontent.com/Flowseal/zapret-discord-youtube/main/.service/version.txt`
(только открывает страницу релиза).

1. **Служба-помощник с правами** («MediaStation Helper», ставится установщиком
   один раз): ставит/меняет службы zapret и AdGuard Home, правила брандмауэра.
   MediaStation общается с ней по именованному каналу. Без неё каждый подбор
   стратегии = окно UAC на ТВ.
2. **Автоподбор стратегии** — логика `test zapret.ps1` в помощнике: по очереди
   `winws` с параметрами каждой стратегии, проверка, лучшая — службой.
   Несколько минут, по кнопке или когда ТВ не используется.
3. **Замер скорости, а не только «открывается»**: для YouTube проблема обычно в
   скорости видео. Скачать несколько МБ реального потока `googlevideo.com`
   (ссылку для тестового ролика — через `yt-dlp`, тоже компонент).
4. **Самоконтроль**: при старте ТВ и раз в N часов — короткая проверка; стала
   плохой — подбор заново + уведомление.
5. **Стратегия для сети**: помнить по шлюзу/MAC роутера или публичному адресу.
6. **Обновления**: раз в сутки `version.txt`; новая версия — на склад, проверка
   SHA-256, остановить службу → заменить `bin/` и `lists/`, **сохранив
   `*-user.txt`** → проверка → если хуже, откат. Без интернета — ничего.
7. Свои домены — в `list-general-user.txt`.

**Ограничения:** автообновление драйвера ядра — риск (подменённый релиз =
полный доступ к компьютеру): проверка хэшей обязательна, по умолчанию —
«скачать и спросить». Конфликтующие программы (Killer, Intel Connectivity
Network Service, Check Point, SmartByte, VPN) показывать в настройках. Если
провайдер блокирует жёстче — «обход не найден», а не бесконечный перебор.
