# Правки 06.11.2026 (2) — подвисания интерфейса, выход из ТВ, путь к LLM

Четвёртый пакет по аудиту: пункт 11 таблицы «Что осталось» (§5, §19) и
быстрые пункты из 12. Проверено: компиляция Windows-ветки (MinGW + заголовки
Qt 6), юнит-тест `tst_tilemanager_structure` (10/10), стенд снимков
`ui_snapshots` на 1280×720 во всех наборах настроек (Qt 6.4, `MultiEffect`
заглушкой). **На медиацентре не проверялось.**

Плюс исправление сборки предыдущего пакета: в `MediaStation.pro` не была
подключена `gdi32` (снимок окна эмулятора, `LNK2019 __imp_CreateCompatibleDC`
и др.).

## 1. Анимация загрузки Android TV — без декодирования в GUI-потоке (§5.2)

`BootAnimationPlayer.qml`: один синхронный `Image` декодировал PNG 60 раз в
секунду именно во время запуска эмулятора. Теперь два `Image` с
`asynchronous: true` по очереди: кадр декодируется в потоке загрузки Qt и
показывается, когда готов; если декодирование не успевает, промежуточные кадры
пропускаются, а не копятся. Логика фаз (логотип → ожидание → доигрывание
цикла) не менялась.

## 2. Фон и картинки с диска (§5.2)

- `Main.qml`: обои загружаются асинхронно и сразу в размере экрана
  (`sourceSize`) — 6000×4000 больше не превращаются в ~96 МБ текстуры при
  старте. Фон всё равно размыт, качество не страдает.
- Иконка плитки (`Tile.qml`) и иконки в списке библиотеки
  (`GameLibraryScreen.qml`) — файлы с диска — `asynchronous: true`. Остальные
  картинки — из ресурсов программы (`qrc:`), им это не нужно.

## 3. Диалог «Новый ярлык» на маленьком экране (§5.1)

- `EditTileDialog.qml`: поля — в прокручиваемой области (полоса прокрутки
  появляется только когда не помещается), кнопки «Отмена»/«Сохранить»
  **закреплены внизу**. На 1280×720 при масштабе 150 % кнопки раньше были на
  y = 765 — за краем окна.
- Диалог при открытии поднимается в корень окна — шапка экрана (часы,
  заголовок) больше не рисуется поверх него.
- `BaseDialog.qml`: карточка любого диалога не выше и не шире окна.

## 4. Чтение папок в фоне (§19 п.3)

`TileManager::listDirAsync(requestId, path, filter)` + сигнал `dirListReady` —
чтение в пуле потоков (`QtConcurrent`). `FileBrowserDialog` показывает
крутилку, ответы на устаревшие запросы (быстрые переходы по папкам)
отбрасывает. Синхронные `listDir`/`listDrives` оставлены для совместимости.

## 5. Установка по сети не переключает экран (§19 п.5)

Раньше принятие установки открывало целевой экран — пользователя «выкидывало»
из настроек или со страницы игры. Теперь плитка добавляется в открытый экран
(если он в стеке) или прямо в хранилище; показывается уведомление
«Установка «…» началась — плитка в разделе «…»». Путь после установки
сохраняет C++ (`TileManager::persistInstallResult`), прогресс подхватит экран,
когда его откроют.

## 6. Диалог обновления — после игры и Android TV (§19 п.6, §2.2 п.5)

`UpdateAvailableDialog.deferred` — пока идёт игра, её запуск или Android TV
(загрузка, показ, переход), диалог не появляется; покажется сам после возврата
в меню.

## 7. Выход из Android TV без ожиданий в GUI-потоке (§1.2 E)

- `stopKeyShell`: `exit` в `adb shell` без ожидания — процесс удалится сам, не
  завершится за 1 с — будет убит. Было до 1,5 с «замирания».
- `stopDnsProxy`, `stopLogcat`: после `kill()` ждём только при закрытии
  программы.
- `Android_TV.log` сбрасывается на диск пачками раз в 250 мс, а не после
  каждой строки (сотни строк при запуске эмулятора). При аварийном завершении
  могут потеряться последние ≤ 0,25 с журнала.

## 8. Настройка `llamaModelPath` и путь к модели (§4 п.3, §9.3)

`GameInfoModule` и `SongNameResolver` читали настройку из
`QSettings("MediaStation","MediaStation")`, а `SettingsManager` пишет в
`("MyCompany","MediaStation")` — настройка была мёртвой. Новый
`tools/LocalModelPaths.h`: одно место для пути к модели и правильная ветка
настроек. Организацию «MyCompany» не переименовывал — там все настройки
пользователя.

## Как проверить

1. Запуск Android TV: анимация загрузки плавная, интерфейс не подвисает.
2. Выход из ТВ через оверлей: меню возвращается сразу, без паузы.
3. Настройки → новый ярлык → «Обзор»: открыть сетевой или спящий диск —
   крутилка, интерфейс живой.
4. Отправить игру с сервера, находясь в настройках, — экран не меняется,
   приходит уведомление, плитка в нужном разделе.
5. Окно 1280×720, масштаб 150 % → «Новый ярлык»: кнопки видны.
