# Правки 06.11.2026 (4) — клавиатура при активном эмуляторе, папка архивов

Проверено: компиляция Windows-ветки и сверка импортов Windows с библиотеками
`MediaStation.pro`; юнит-тесты `tst_gamelibrarymodule_scan` (6/6),
`tst_settingsmanager` (5/5), `tst_tilemanager_structure` (10/10); стенд снимков.
**На медиацентре не проверялось.**

## 1. Esc и стрелки не работают, пока не нажать Win (после схемы B)

**Что видно.** Клавиши пропадают ровно тогда, когда активно окно эмулятора:
так было в исходной жалобе (фокус оставался у эмулятора) и снова стало после
схемы B, где эмулятор активен намеренно. Дальше нашего перехватчика клавиши не
теряются — путь «хук → шина → консоль эмулятора» проверен по коду.

**Вероятная причина.** Низкоуровневые перехватчики клавиатуры вызываются от
последнего установленного к первому. Эмулятор, став активным, ставит свой —
он оказывается раньше нашего и съедает клавиши. Win переключает активное окно,
и перехватчик эмулятора перестаёт мешать.

**Что сделано** (`G72KeysModule`):
- переустановка нашего перехватчика — сразу после передачи активности
  эмулятору, ещё раз через 0,4 с и дальше каждые 2 с, пока идёт ТВ. Новый
  ставится до снятия старого — без «дыры»;
- диагностика: в `MediaStation.log` строка
  `[G72Keys] First key in TV mode reached the hook: vk=…, foreground class='…'`
  — первая клавиша в режиме ТВ дошла до перехватчика.

Если строки нет, а клавиши не работают — клавиши съедает не перехватчик, и
нужен запасной вариант: оставить активным невидимое окно MediaStation
(часть выигрыша схемы B для звука при этом теряется).

## 2. Папка архивов игр и проверка места (§15 п.4)

- Настройки → Игры: **«Папка для архивов игр»** рядом с «Папкой для установки
  игр». Пусто (по умолчанию) — как раньше, архив внутри папки игры
  (`<игра>/archive/`). Кнопка с корзиной — вернуть к варианту по умолчанию.
- В общей папке архив называется `<имя папки игры>_<6 символов id>.7z` — игры
  с одинаковыми именами из разных мест не перезапишут друг друга.
- Старые архивы находятся по-прежнему: путь из `game_info.json`, затем папка
  архивов из настроек, затем внутри папки игры.
- **Проверка места до начала**: размер игры (известный или подсчитанный) + 1 ГБ
  против свободного места на диске архива. Не хватает — архивация не
  начинается, уведомление: «мало места на диске D:/ — нужно до N ГБ, свободно
  M ГБ», плитки возвращаются.
- Общую папку архивов программа не удаляет, даже если она опустела.
