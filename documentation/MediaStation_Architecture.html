1. Общая архитектура

Проект построен по модульной архитектуре. C++ слой содержит ядро (core/), модули бизнес-логики, набор вспомогательных утилит (tools/) и использует внешние бинарные инструменты (external_tools/). QML слой — весь UI. Взаимодействие между C++ модулями происходит исключительно через EventBus. Модули не знают друг о друге напрямую.

Ключевые свойства архитектуры

  • Потокобезопасность: фоновые модули (G72BatteryModule, InstallManager, GameLibraryModule, GameInfoModule, GameMediaModule) используют Qt-сигналы с автоматическим QueuedConnection и явным флагом занятости. applicationDirPath() кешируется в GUI-потоке при старте.
  • Жизненный цикл: ModuleHost управляет порядком инициализации и завершения. shutdown() у каждого модуля вызывается в порядке, обратном регистрации, до уничтожения объектов.
  • Протокол событий: типизированные сигналы EventBus — для межмодульных событий; moduleEvent() — для расширения без правок EventBus.h. Протоколы moduleEvent закреплены как именованные константы в namespace соответствующего модуля.

Схема уровней

  • QML слой
    Экраны: Main, HomeScreen, DynamicScreen, GameDetailScreen, SettingsScreen, GameLibraryScreen, AndroidTvSettings и др.
    Базовые компоненты: BaseDialog, GlowingCard, StyledButton, Spinner, ToggleSwitch и др.
  • Модули C++
    TileManager, InstallManager, NetworkListener, AppController (+GameWatcher), JoystickModule, SettingsManager, NotificationModule, G72BatteryModule, GameLibraryModule, G72KeysModule, AndroidTVModule, GameInfoModule, GameMediaModule, LoggerModule, OverlayModule, UpdateManager
  • Ядро (core/)
    ModuleHost, EventBus, IModule
  • Утилиты (tools/)
    AtomicFile (атомарная запись), HttpClient (синхронный HTTP GET), LlamaClient (LLM инференс), SevenZip (архивация/разархивация через 7zr)
  • Внешние инструменты (external_tools/)
    7zr.exe, ffmpeg.exe, DS4WindowsCmd.exe, PEDependencyAnalyzer.exe, adb.exe, dnsproxy.exe, llama.dll, applications.json
  • Вспомогательные классы (не IModule)
    GameWatcher, GameInfoFetcher, HtmlStripper, TitleNormalizer, InstallUtils, CoverFetcher, TrailerFetcher, SteamAppList

EventBus: два уровня событий

Типизированные сигналы (добавляются редко):

// NetworkListener → InstallManager
void networkExtractFinished(tileId, title, gameRootPath, exeRelPath, iconRelPath, kind);

moduleEvent(module, event, data) — для расширения без правки EventBus.h:

// Уведомления

// GameLibraryModule ↔ TileManager

// G72KeysModule → AndroidTVModule
emit bus->moduleEvent(G72Keys::kModule, G72Keys::kEventKey, ...);

// GameInfoModule → шина
emit bus->moduleEvent("gameinfo", "fetch", data);
emit bus->moduleEvent("gameinfo", "fetched", data);

// GameMediaModule
emit bus->moduleEvent("gamemedia", "fetch", ...);

4. Утилиты (tools/) — вспомогательные классы

Набор потокобезопасных вспомогательных классов, используемых модулями. Все утилиты блокирующие — вызывать только из фоновых потоков.

AtomicFile

Атомарная запись файлов через паттерн .tmp → rename. Гарантирует, что файл либо записан полностью, либо не тронут. Используется в TileManager (structure.json), GameInfoModule (game_info.json), GameMediaModule (обновление метаданных).

// Запись JSON
AtomicFile::writeJson("/path/file.json", doc);

// Запись произвольных байт
AtomicFile::writeBytes("/path/image.jpg", data);

HttpClient

Синхронный HTTP GET для фоновых потоков. Использует QEventLoop и таймауты. Поддерживает флаг отмены через std::atomic<bool>*. Применяется в CoverFetcher, TrailerFetcher, GameInfoFetcher.

QByteArray data = HttpClient::get("https://...", 30000, &m_cancelled);

LlamaClient

Обёртка над llama.cpp для инференса LLM (Qwen2.5-7B). Управляет моделью (загрузка в GPU/CPU, контекст 12288 токенов, генерация до 2048 токенов). Поддерживает колбэк на каждый токен. Логирует через EventBus → LoggerModule. Используется в GameInfoModule для генерации описаний.

LlamaClient client;
client.setBus(eventBus);
client.initialize("/path/model.gguf");
QString result = client.runInference(systemPrompt, userPrompt,
    [](const QString &token){ /* потокобезопасный вывод */ });

Важно: отключает CUDA Graph через GGML_CUDA_NO_GRAPHS=1 для стабильности.

SevenZip

Обёртка над 7zr.exe (или 7z.exe) для сжатия/распаковки .7z с максимальным сжатием LZMA2. Предоставляет прогресс-колбэк. Используется в GameLibraryModule (архивация/разархивация игр).

SevenZip::Result r = SevenZip::compress(workDir, "game", archivePath, &cancelFlag,
    [](int pct, const QString &file){ /* прогресс */ });

6. Модули C++

TileManager (modules/TileModule/)

Отвечает за дерево плиток и файл structure.json. Логика установки полностью делегирована InstallManager. Использует AtomicFile для атомарной записи структуры.

InstallManager (modules/TileModule/)

Полноценный модуль, отвечающий за установку, создание ярлыков, сканирование зависимостей. Работает в фоновом потоке.

NetworkListener (modules/NetworkModule/)

TCP-сервер, принимающий и распаковывающий пакеты установки. Сигнал networkExtractFinished потребляется напрямую InstallManager.

AppController + GameWatcher (modules/AppModule/)

Управление запуском приложений и игр. GameWatcher — внутренний класс, наблюдающий за окном запущенной игры через Win32 API.

JoystickModule (modules/JoystickModule/)

Управление геймпадами и DS4Windows.

SettingsManager (modules/SettingsModule/)

Хранит настройки через QSettings. Изменения пробрасываются в EventBus::settingChanged.

NotificationModule (modules/NotificationModule/)

Управление очередью уведомлений с приоритетами.

G72BatteryModule (modules/AirMouseModule/)

Чтение заряда пульта G72 по BLE (WinRT) в фоновом потоке.

GameLibraryModule (modules/GameLibraryModule/)

Библиотека игр: сканирование installPath, метаданные, архивирование/разархивирование через SevenZip.

G72KeysModule (modules/AirMouseModule/)

Обрабатывает нажатия клавиш пульта G72 через Win32 хуки.

AndroidTVModule (modules/AndroidTVModule/)

Управляет эмулятором Android TV (запуск, управление через ADB, DNS-proxy).

GameInfoModule (modules/GameInfoModule/)

Модуль получения метаданных об игре с использованием локальной БД, веба и LLM (LlamaClient). После успешного получения информации автоматически инициирует загрузку медиа через GameMediaModule.

GameMediaModule (modules/GameMediaModule/)

Отвечает за загрузку обложек, фонового изображения и трейлера игры со Steam CDN / API. Использует HttpClient, CoverFetcher, TrailerFetcher (ffmpeg для конвертации).

LoggerModule (modules/LoggerModule/)

Принимает события логирования через moduleEvent("logger", "log", ...) и записывает их в файл logs/app.log.

OverlayModule (modules/OverlayModule/)

Управляет оверлейным окном (отображается поверх игр).

UpdateManager (modules/UpdateManager/)

Проверка обновлений приложения через GitHub API.

7. QML слой

7.1 Экраны и основные компоненты

Ключевые QML-экраны и виджеты.

  • Main.qml — корневой экран.
  • Settings.qml — синглтон-прокси для настроек, функции us() и fs().
  • DynamicScreen.qml — динамическая сетка плиток, поддержка фаз установки.

  • Tile.qml — плитка с иконкой, прогресс-бар, зона отмены, контекстное меню.
  • G72BatteryWidget.qml — индикатор заряда пульта.
  • ...

7.2 Базовые UI компоненты (qml/base/)

Набор переиспользуемых компонентов для построения интерфейса. Все они находятся в папке qml/base/ и используют синглтон Settings для масштабирования и стилизации.

BaseDialog

Модальное окно с затемнением фона и анимацией появления/скрытия.

  • dialogWidth, dialogHeight — размеры карточки.
  • closeOnClickOutside — закрытие по клику вне карточки.
  • Методы: open(), close().

GlowingCard

Контейнер с тенью, градиентным фоном и акцентной рамкой.

SectionDivider

Горизонтальная разделительная линия.

SettingsRow

Строка для элементов настроек: слева метка, справа контент.

SettingsTile

Карточка-ссылка для экранов настроек.

Spinner

Индикатор загрузки в виде вращающейся дуги.

StyledButton

Стилизованная кнопка с ролями: primary, danger, default.

ToggleSwitch

Переключатель (аналог checkbox) с анимацией.

10. Типичные сценарии изменений

  • Добавление нового HTTP-запроса → использовать HttpClient::get в фоновом потоке с флагом отмены.
  • Смена модели LLM → заменить .gguf, проверить параметры kCtxSize, kMaxTokens в LlamaClient.cpp.
  • Атомарная запись нового конфига → использовать AtomicFile::writeJson или writeBytes.
  • Архивация/распаковка другого формата → расширить SevenZip новыми параметрами.
  • Новый тип уведомления → NotificationLevel enum, Notification.qml
  • Добавление настройки → SettingsManager, Settings.qml, ModuleHost.cpp
  • Добавить новый модуль → два файла .h/.cpp + строка в main.cpp

13. Формат game_info.json

Атомарно обновляется через AtomicFile::writeJson.

{
  "id": "a3f1c8d9e2b4",
  "name": "Half-Life 2",
  "type": "installed",
  "coverPath": "C:\\Games\\Half-Life 2\\launcher\\media\\cover.jpg",
  "backdropPath": "...",
  "trailerPath": "...",
  "mediaFetched": true,
  "description": "...",
  "genre": "..."
}

Жизненный цикл type

installed ↔ archive (архивирование/разархивирование)
external → (нельзя архивировать)
