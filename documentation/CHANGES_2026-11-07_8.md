# Правки 07.11.2026 (8) — по журналу проверки v10

## 1. Быстрый ввод в ТВ (gRPC) не включался

Журнал: `gRPC unavailable (grpc-status 16: The token … is invalid)`. С флагом
`-grpc-use-token` эмулятор создаёт **свой** токен и пишет его в файл
обнаружения `%TEMP%\avd\running\pid_<PID>.ini` (`grpc.token=…`), а программа
брала токен консоли (`.emulator_console_auth_token`). Из-за этого кнопки шли
медленным запасным путём (`adb input keyevent`) — отсюда «не особо плавно».

Теперь токен берётся из файла обнаружения: путь — из строки эмулятора
`Advertising in: …`, иначе `pid_<PID эмулятора>.ini`, иначе любой файл с нашим
портом gRPC. В журнал пишется, откуда взят токен:
`[Input] gRPC token: grpc.token from …`.

## 2. AdGuard Home — кнопка «Скачать»

Журнал: `AdGuard Home not installed`. Теперь не нужно запускать
`setup_android_sdk.bat`: Настройки → Android TV → «Служба AdGuard Home» →
«Скачать AdGuard Home» (последний релиз с GitHub, распаковка встроенным в
Windows `tar.exe`), затем «Установить службу».
