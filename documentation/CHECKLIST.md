# Чек-лист проверки на медиацентре

Что сделано и проверено только сборкой и тестами на Linux — проверить на
медиацентре. Порядок — от важного. Отмечайте `[x]`; строки журнала искать в
`logs/Android_TV.log` и `logs/MediaStation.log`. Если что-то не так — пришлите
оба журнала и номер пункта.

Обновлено: 07.11.2026 (архив `MediaStation_2026-11-07_v12`).

---

## 0. Сборка

- [ ] Проект собирается в Qt Creator (MSVC, Release) без ошибок компоновки.

## 1. Android TV — запуск и показ

- [ ] Запуск ТВ: затемнение → плавное появление Android, **без белого и
      чёрного экрана**.
- [ ] Во время загрузки окно эмулятора нигде не мелькает (ни поверх меню, ни
      на панели задач).
- [ ] Картинка ТВ чёткая (не растянутая 1080p на экране 1440p).
      Журнал: `Resolution 'auto' → detected screen resolution 2560x1440`.
- [ ] Если ТВ не запустился с первого раза — запустить ещё раз (см. п. 2,
      флаги gRPC). Журнал: `Emulator does not support -grpc options`.

## 2. Android TV — управление

- [ ] Стрелки, OK, «Назад» с **клавиатуры** и **пульта** листают Android сразу,
      без нажатия Win.
- [ ] Быстрый ввод через gRPC. Журнал: `[Input] gRPC token: grpc.token from …`,
      `[Input] gRPC :8554 ready` и `[Input] gRPC probe: OK, keys reach Android`.
      Если вместо этого `gRPC unavailable (…)` или `gRPC input disabled (…)` —
      прислать журнал (работать будет, но через медленный adb).
- [ ] «Домой» с пульта возвращает на главный экран Android.
- [ ] Обычные буквы и Backspace с клавиатуры набираются в поиске Android и в
      пароле Wi-Fi.

## 3. Android TV — оверлей

- [ ] Esc / «Меню» открывает оверлей **сразу**, без нажатия Win.
- [ ] Оверлей появляется плавно, без рывков, панель у нижнего края.
- [ ] ТВ под оверлеем затемнён, **не чёрный** (особенно при первом открытии).
- [ ] Удержание Esc не открывает-закрывает оверлей по кругу.
- [ ] «Продолжить» — стрелки снова листают Android.
- [ ] «Выйти» — возврат в меню сразу, без паузы; курсор мыши на прежнем месте.

## 3а. Android TV — блокировка рекламы (AdGuard Home)

- [ ] Настройки → Android TV → «Скачать AdGuard Home» — загрузка с процентами,
      уведомление «AdGuard Home скачан».
- [ ] Настройки → Android TV → Общие: «Блокировка рекламы» — «Служба не
      установлена»; «Установить службу» → окно Windows «Разрешить?» → «Да» →
      уведомление, статус «Работает».
- [ ] Запуск ТВ. Журнал `Android_TV.log`:
      `ad blocking: AdGuard Home answers on 127.0.0.1:53` и
      `Using DNS: 127.0.0.1 (AdGuard Home)`.
- [ ] **Интернет в ТВ работает** (YouTube открывается, видео идёт). Если нет —
      выключить «Блокировка рекламы», перезапустить ТВ, прислать журнал.
- [ ] «Открыть панель» — в браузере панель AdGuard Home, в «Журнале запросов»
      видны запросы ТВ, часть заблокирована.
- [ ] Если в журнале `does not answer on 127.0.0.1:53` — прислать журнал
      (скорее всего порт 53 занят другой программой).

## 4. Android TV — звук (схема B)

- [x] Схема B проверена 07.11: хрипы остались — звук берётся в работу
      отдельно (`STATUS_2026-11-07.md` §5).
- [ ] 30–40 минут видео в ТВ: заикания реже, чем раньше?
- [ ] Листание стрелками во время видео не вызывает рывков звука
      (зависит от п. 2 — gRPC).
- [ ] Прислать `MediaStation.log` — строки `Audio: … delayed … underruns`
      за этот сеанс.

## 5. Интерфейс

- [ ] Анимация загрузки ТВ плавная, меню не подвисает при запуске ТВ.
- [ ] Окно 1280×720, масштаб 150 % → «Новый ярлык»: кнопки «Отмена» /
      «Сохранить» видны.
- [ ] «Обзор» в новом ярлыке, открыть сетевой или «спящий» диск — крутилка,
      интерфейс не замирает.
- [ ] Отправить игру с сервера, находясь в настройках, — экран не
      переключается, приходит уведомление, плитка в нужном разделе.
- [ ] Диалог обновления не появляется во время игры и ТВ — только после
      возврата в меню.

## 6. Игры — папка архивов

- [ ] Настройки → Игры → «Папка для архивов игр»: указать папку на другом
      диске, заархивировать игру — архив в этой папке.
- [ ] Разархивировать ту же игру обратно — запускается.
- [ ] Старая игра, заархивированная раньше (архив в папке игры), находится и
      разархивируется.
- [ ] Мало места на диске архивов — архивация не начинается, уведомление
      «мало места … нужно … свободно …».

- [ ] Мало места на диске игры — распаковка не начинается, уведомление
      «… не распакована: мало места …».
- [ ] Библиотека игр: размеры показываются сразу (из кэша); после
      обновления игры (новые файлы) размер пересчитывается.

- [ ] Библиотека → удержание на игре → «Сжать (игра останется рабочей)» →
      «Сжать»: полоса прогресса, затем уведомление «… сжата: N → M ГБ»,
      статус «Установлена, сжата», размер уменьшился.
- [ ] Сжатая игра запускается и играется как обычно.
- [ ] «Снять сжатие» — размер возвращается; при нехватке места — уведомление
      и ничего не начинается.
- [ ] Крестик во время сжатия останавливает его, игра продолжает работать.
- [ ] Запуск игры стал быстрее. Журнал: `[GameWatcher] started directly: …`.
      Если вместо этого `direct start failed (…), using launch.ps1` —
      прислать журнал (игра всё равно запустится, как раньше).
- [ ] Игра, которой нужны права администратора, — Windows спрашивает, игра
      запускается.

## 7. Android TV — профили

- [ ] Настройки → Android TV → профили: «Удалить профиль» спрашивает про
      данные; «Удалить с данными» — папка `<имя>.avd` в
      `tools/android-tv/avd` исчезает; «Оставить данные» — остаётся.

## 8. Караоке

- [ ] Выбрать mp3 с нормальными тегами (в т.ч. русскими) — исполнитель и
      название берутся из тегов сразу, без «нейросеть думает».
- [ ] То же для FLAC.

- [ ] Вход в караоке: подвисает? Если да — прислать `MediaStation.log`, строки
      `[UI] screen created in … ms` и `interface was unresponsive … (screen:
      Караоке)`.

## 9. Нейросети

- [ ] Если в настройках задан свой путь к модели LLM (`llamaModelPath`) —
      описание игры и разбор названий песен используют его.
