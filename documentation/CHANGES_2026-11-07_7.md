# Правки 07.11.2026 (7) — блокировка рекламы в Android TV: AdGuard Home (§23)

Проверено: компиляция Windows-ветки и наличие функций WinAPI в подключённых
библиотеках (добавлены `shell32`, `ole32` — для `ShellExecuteEx`); новый тест
`tst_adguardhome` (8/8) — в т.ч. **с настоящим AdGuard Home v0.107.80**:
наша конфигурация запускается, сервер отвечает на проверку, домен из
локального списка блокируется; стенд снимков интерфейса. **На медиацентре не
проверялось** — пункты в `CHECKLIST.md`, раздел 3а.

## Что было

Эмулятору передавался `-dns-server 8.8.8.8,1.1.1.1`, а dnsproxy слушал порт
5300, которым эмулятор не пользуется. Список блокировки писался в
`/system/etc/hosts` через `adb root` — на образе с Google Play это невозможно,
а `adb root` лишь перезапускал adbd. Реклама не блокировалась вовсе.

## Как теперь

- `tools/adguardhome/AdGuardHome.exe` — скачивает `setup_android_sdk.bat`
  (вместо создания `dnsproxy.yml`).
- Настройки → Android TV → Общие: «Блокировка рекламы» (вкл/выкл, состояние
  службы), «Установить службу» / «Удалить службу» (окно Windows с запросом
  прав — один раз), «Открыть панель» (http://127.0.0.1:3080).
- При установке MediaStation пишет `AdGuardHome.yaml` (если его нет — правки
  пользователя не трогаются): DNS только `127.0.0.1:53`, панель только
  `127.0.0.1:3080` без пароля, DoH (Google, Cloudflare, Яндекс) с запасными
  обычными DNS, списки — локальный `userfilters/mediastation.txt` (сюда
  переносятся домены из старого `blocklists/default.txt`) и AdGuard DNS
  filter; YouTube, Google Video и картинки YouTube — в белом списке.
- Перед запуском ТВ — проверка `127.0.0.1:53` (DNS-запрос, ≤ 0,7 с,
  параллельно с перезапуском adb). Ответил — эмулятору `-dns-server
  127.0.0.1`; нет — DNS из профиля, как раньше, и строка в журнале.
- Весь Windows на 127.0.0.1 не перенаправляется — только эмулятор.
- Убраны: dnsproxy (`startDnsProxy`/`stopDnsProxy`), `applyBlocklist`
  (`adb root`, `remount`, `push hosts`).

## Ограничения

Рекламу внутри YouTube DNS не убирает. Если порт 53 на 127.0.0.1 занят другой
программой — AdGuard Home не запустится (пока без запасного адреса,
пункт в аудите).
