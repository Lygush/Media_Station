## 1. sendevent через su

Образ `system-images;android-34;android-tv;x86` — без Google Play, в нём есть
`su`. Проверка устройства теперь:
- выясняет, работает ли `su 0` (строка `SU_OK`), и тогда читает список
  устройств через `su 0 getevent -pl`;
- если своего права записи нет, но su работает — пачка нажатий уходит одной
  командой `su 0 sh -c 'sendevent …;sendevent …'` (su и sendevent — нативные
  утилиты, без JVM);
- если не годится ничего — в журнале подробности:
  `no usable keyboard device (devices seen N, writable M, su yes/no)`.

## 2. Неработающая консоль запоминается

Результат «консоль не доставляет события» сохраняется в настройках с
привязкой к сборке эмулятора (размер и дата `emulator.exe`). При следующих
запусках ТВ проверка не повторяется — первое нажатие без задержки 1,8 с.
После обновления эмулятора консоль проверится заново.

## 3. Чёрный эмулятор под оверлеем при первом Esc

Вероятная причина: после смены активного окна GL-окно эмулятора не
перерисовывается, пока Android не пришлёт новый кадр (меню неподвижно).
При открытии оверлея эмулятор просится перерисоваться — сразу и через 120 мс.
Это предположение — проверка на медиацентре.
