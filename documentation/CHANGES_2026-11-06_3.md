# Правки 06.11.2026 (3) — схема B: эмулятор на переднем плане

Аудит §1.2 B (пункт 2 таблицы). Проверено: компиляция Windows-ветки и
сверка всех импортируемых функций Windows с библиотеками из
`MediaStation.pro` (та же проверка находит пропущенную `gdi32` из прошлого
пакета). **На медиацентре не проверялось.**

## Что было

Во время просмотра ТВ поверх эмулятора постоянно висело полноэкранное окно
MediaStation — TOPMOST, прозрачное (alpha 0) и активное. Эмулятор был
фоновым процессом: меньший квант планировщика, риск EcoQoS/E-ядер, лишняя
композиция DWM поверх видео. По аудиту — главная оставшаяся причина
периодического заикания звука.

## Что сделано

| Момент | Раньше | Теперь |
|---|---|---|
| ТВ проявился | MediaStation прозрачный поверх, активен | Эмулятор — **активное окно**, MediaStation — `SW_HIDE` (Qt перестаёт его рисовать) |
| Открыт оверлей | alpha 0 → 128 | MediaStation показывается без активации (alpha 0, TOPMOST), затем плавно 0 → 128 |
| Оверлей закрыт | alpha 128 → 0 | 128 → 0, затем MediaStation снова прячется, эмулятор — активный |
| Выход из ТВ | alpha → 255 | MediaStation показывается (непрозрачный), потом прячется эмулятор |
| Курсор | Скрыт Qt над MediaStation | Убран к правому краю экрана, в режиме ТВ хук мыши не даёт его двигать; на выходе — на прежнее место |

Попутно: обычные буквы с клавиатуры теперь доходят до Android (окно
эмулятора активно) — поиск и пароли Wi-Fi можно набирать. Стрелки, Enter и
Esc по-прежнему перехватывает хук (Esc = оверлей).

Оверлей: панель опущена к нижнему краю экрана (отступ 36 вместо 120).

## Строки журнала `Android_TV.log`

- `MediaStation hidden, emulator is foreground=1` — схема работает.
- `foreground=0` или `WARNING: emulator could not take foreground` — Windows не
  отдала активность эмулятору.
