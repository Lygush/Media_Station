# Правки 07.11.2026 (9) — по журналу проверки v11

## 1. gRPC: успешный ответ считался ошибкой

Журнал: `gRPC unavailable (grpc-status 0, 0: )`. Токен теперь верный, эмулятор
отвечает «0» (успех) — и в заголовке, и в конце ответа; Qt склеивает их в
«0, 0», а проверка ждала ровно «0». Теперь «0, 0» — успех
(`EmulatorGrpcClient::statusIsOk`). Заодно для вызовов gRPC выключен HTTP-кэш
Qt (ошибки `caching was enabled after some bytes had been written` в журнале).

## 2. AdGuard Home: служба работает, но DNS не отвечает

Журнал: `AdGuard Home does not answer on 127.0.0.1:53 (service running)`.
Причину по журналу не видно, поэтому:
- проверка — до 3 попыток (служба могла только что запуститься);
- при неудаче в журнал пишется диагностика `ad blocking diagnostics: …`:
  ответ панели AdGuard Home (`/control/status`), отвечает ли мастер первого
  запуска на :3000 (значит, служба не нашла `AdGuardHome.yaml`), и какая
  программа держит порт 53 (`netstat -ano` + `tasklist`).
